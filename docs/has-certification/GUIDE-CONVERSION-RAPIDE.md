# 🚀 GUIDE CONVERSION RAPIDE : MARKDOWN → WORD
## Pas besoin de Pandoc ! Utilisez directement Word

---

## ⚡ MÉTHODE ULTRA-RAPIDE (2 minutes par fiche)

### Étape 1 : Ouvrir dans Word

1. **Lancez Microsoft Word**

2. **Fichier → Ouvrir** (ou Ctrl+O)

3. **Naviguez vers :**
   ```
   /home/user/ehpad-connect/docs/has-certification/fiches-imperatifs/
   ```

4. **Sélectionnez une fiche** (ex: `3.1-1-identification-resident.md`)

5. **Cliquez sur "Ouvrir"**

✨ **Word convertit automatiquement le Markdown en document formaté !**

---

### Étape 2 : Appliquer les couleurs Belle Viste (optionnel)

**Si vous voulez une mise en forme rapide, voici les raccourcis :**

#### Pour les TITRES H1 (Critère impératif X.X-X)

1. **Sélectionnez** le titre principal
2. **Police** : Arial
3. **Taille** : 18
4. **Gras** : Ctrl+G (ou bouton G)
5. **Couleur** :
   - Cliquez sur la flèche à côté de **A** (couleur de police)
   - **Autres couleurs...**
   - Onglet **Personnalisées**
   - **RVB** : Rouge=**46**, Vert=**83**, Bleu=**57**
   - OK

#### Pour les TITRES H2 (1. RÉFÉRENTIEL HAS, 2. EXIGENCES CLÉS, etc.)

Même procédure avec :
- **RVB** : Rouge=**139**, Vert=**157**, Bleu=**131**

---

### Étape 3 : Enregistrer au format Word

1. **Fichier → Enregistrer sous**

2. **Choisir l'emplacement** (ex: Bureau ou dossier HAS)

3. **Type** : Document Word (*.docx)

4. **Nom** : Gardez le même nom (ex: `3.1-1-identification-resident.docx`)

5. **Enregistrer**

## 💡 ASTUCE : CRÉER UN STYLE PERSONNALISÉ

**Pour aller encore plus vite sur les 8 fiches :**

### Créer le style "Titre HAS H1"

1. Sur la **première fiche**, formatez un titre H1 avec les bonnes couleurs
2. **Sélectionnez** ce titre
3. Dans le ruban **Accueil** → panneau **Styles**
4. Clic droit sur "Titre 1" → **Modifier**
5. Appliquez : Arial 18pt, Gras, Vert Sapin (R=46, G=83, B=57)
6. Cochez **"Mettre à jour automatiquement"**
7. **OK**

### Créer le style "Titre HAS H2"

Même procédure avec :
- Arial 14pt, Gras, Vert Sauge (R=139, G=157, B=131)

**Ensuite** : Sur les fiches suivantes, il suffira de cliquer sur "Titre 1" ou "Titre 2" dans le panneau Styles !

## 📊 FORMATAGE DES TABLEAUX (optionnel)

Pour que les tableaux aient les bonnes couleurs :

1. **Sélectionnez le tableau**

2. **Création de tableau** (onglet qui apparaît)

3. **Styles de tableau** → Choisir un style clair

4. **Personnaliser** :
   - Ligne d'en-tête : Fond Vert Menthe (R=200, G=230, B=201)
   - Bordures : Vert Sauge (R=139, G=157, B=131)

## 🆘 PROBLÈMES COURANTS

**"Je ne trouve pas le fichier .md dans Word"**
→ Dans la fenêtre "Ouvrir", assurez-vous que le filtre de fichiers est sur "Tous les fichiers (*.*)" au lieu de "Documents Word"

**"Les tableaux sont mal affichés"**
→ C'est normal, ajustez manuellement la largeur des colonnes

**"Les émojis ne s'affichent pas"**
→ Vérifiez que votre version de Word supporte les émojis (Word 2016+)

**"Je n'ai pas Microsoft Word"**
→ Utilisez **Google Docs** (gratuit) :
  1. Importer le fichier .md
  2. Télécharger au format Word

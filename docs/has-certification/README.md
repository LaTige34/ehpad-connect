## 🎨 CHARTE GRAPHIQUE BELLE VISTE

### Couleurs officielles

- **Vert Sapin** : `#2E5339` (titres H1, bordures principales)
- **Vert Sauge** : `#8B9D83` (tableaux, titres H2)
- **Vert Menthe** : `#C8E6C9` (encadrés, arrière-plans)
- **Police** : Arial

### Application dans Word

1. **Titres H1** (ex: "Critère impératif 3.1-1") : Arial 18pt, Gras, Vert Sapin #2E5339
2. **Titres H2** (ex: "1. RÉFÉRENTIEL HAS") : Arial 14pt, Gras, Vert Sauge #8B9D83
3. **Tableaux** : Bordures Vert Sauge #8B9D83, en-têtes avec fond Vert Menthe #C8E6C9
4. **Encadrés** (Points clés, Messages) : Bordure Vert Sapin, fond Vert Menthe #C8E6C9
5. **Bordures de page** : Vert Sapin #2E5339, 2pt

## 📊 STRUCTURE COMMUNE DE CHAQUE FICHE

Toutes les fiches suivent la même structure en 8 sections :

1. **Référentiel HAS** : Définition du critère et éléments d'appréciation
2. **Exigences clés** : Points essentiels à démontrer
3. **Actions prioritaires (6 semaines)** : Tableau avec priorités 🔴🟠🟡
4. **Preuves à préparer** : Documents, traçabilité, indicateurs
5. **Points vigilance entretien** : Questions probables des évaluateurs
6. **Exemples réponses évaluateurs** : 4-5 réponses types détaillées
7. **Points clés à retenir** : Les 5 essentiels + message clé pour l'équipe
8. **Ressources complémentaires** : Outils, contacts, références

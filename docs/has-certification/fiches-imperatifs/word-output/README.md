## 📝 PROCHAINES ÉTAPES

### 1. Ouvrir les fichiers dans Microsoft Word

Double-cliquez sur chaque fichier `.docx` pour l'ouvrir dans Word.

### 2. Ajustements recommandés

Les fichiers sont prêts à l'emploi, mais vous pouvez :

- **Ajouter le logo** Belle Viste dans l'en-tête
- **Personnaliser** les noms des référents (remplacer [NOM])
- **Ajuster les tableaux** (largeur des colonnes)
- **Ajouter des bordures de page** (Mise en page → Bordures)
- **Créer en-tête/pied de page** :
  - En-tête : "EHPAD Belle Viste - Saint-Gély-du-Fesc (70 lits)"
  - Pied de page : "Certification HAS novembre 2024 - Page X/Y"

### 3. Finaliser la mise en page

**Tableaux** :
- Les tableaux peuvent nécessiter un ajustement manuel
- Appliquer des bordures Vert Sauge (#8B9D83)
- Fond d'en-tête Vert Menthe (#C8E6C9)

**Encadrés** (Points clés à retenir) :
- Ajouter des bordures vertes et fond Vert Menthe
